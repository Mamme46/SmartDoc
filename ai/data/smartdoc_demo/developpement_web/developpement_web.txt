La maintenance et l'accessibilité doivent être prévues dès les premières maquettes.
Une application web relie une interface visible dans le navigateur à un serveur qui traite les requêtes et manipule parfois une base de données. HTML structure le contenu, CSS organise l'affichage et JavaScript ajoute des interactions. Une page bien conçue doit rester utilisable sur un petit écran comme sur un ordinateur, avec des formulaires compréhensibles et des messages d'erreur précis.

Côté serveur, les routes reçoivent les données, vérifient les droits et appellent les services nécessaires. La validation ne doit jamais être confiée uniquement au navigateur, car une requête peut être fabriquée directement. Les mots de passe sont stockés sous forme de hachages adaptés, et les secrets de configuration restent en dehors du code partagé. Les protections contre les injections, les scripts intersites et les requêtes forgées font partie du développement courant.

Les outils de contrôle de version permettent de travailler par petites modifications et de retrouver l'origine d'un changement. Des tests automatisés couvrent les fonctions importantes, tandis qu'une vérification manuelle explore les parcours réels. Les journaux doivent aider au diagnostic sans enregistrer de données confidentielles. Une application web robuste résulte donc autant de l'architecture et de la sécurité que de son apparence.
